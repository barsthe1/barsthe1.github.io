Privacy Policy

extella-drive · last updated 24 October 2026

1. What extella-drive is

extella-drive is a private, single-user utility. It is operated by the owner of this site to copy, back up and verify his own files between his cloud storages and his private server. It is not distributed to the public and has no users other than its owner.

2. What data the application accesses

With the owner's explicit consent, given through Google's OAuth sign-in, the application accesses files in the owner's own Google Drive (Google API scope https://www.googleapis.com/auth/drive). It uses this access to upload files, list folders, read file metadata and checksums, and remove or move files that the owner has decided to remove or move. The application does not access the data of any other person.

3. How the data is used

The data is used solely to copy, back up and verify the owner's files. There is no analytics, profiling, advertising, or any processing beyond the transfer and verification of files.

4. Where the data is stored and how it is protected

Google OAuth tokens are stored on the owner's private server in a configuration file readable only by the server's administrator account and used only by the open-source program rclone and the owner's scripts. Files pass through that server in transit between storages and are not kept there beyond the transfer. Log files on the server record file names, sizes, checksums and timestamps of transfers.

5. Sharing with third parties

No data obtained through Google APIs is shared with, sold to, transferred to or disclosed to any third party.

6. Retention and revocation

The owner can revoke the application's access at any time at myaccount.google.com/permissions; revocation invalidates the stored tokens. All files in Google Drive remain under the owner's control through Google Drive itself.

7. Google API Services User Data Policy

extella-drive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Contact

Questions about this policy can be sent to the support e-mail address shown on the application's Google sign-in (consent) screen.

Политика конфиденциальности

extella-drive · обновлено 24 октября 2026

1. Что такое extella-drive

extella-drive — личная утилита с одним пользователем. Ею владелец этого сайта копирует, резервирует и сверяет свои собственные файлы между своими облачными хранилищами и своим частным сервером. Она не распространяется и не имеет других пользователей, кроме владельца.

2. К каким данным обращается приложение

С явного согласия владельца, данного через вход Google (OAuth), приложение обращается к файлам в Google Диске самого владельца (область доступа https://www.googleapis.com/auth/drive). Доступ нужен, чтобы загружать файлы, перечислять папки, читать метаданные и контрольные суммы, а также удалять или перемещать файлы, которые владелец решил удалить или переместить. К данным других людей приложение не обращается.

3. Как используются данные

Данные используются только для копирования, резервирования и сверки файлов владельца. Никакой аналитики, профилирования, рекламы или иной обработки, кроме передачи и сверки файлов, нет.

4. Где хранятся данные и как защищены

Токены Google OAuth хранятся на частном сервере владельца в файле настроек, доступном только администратору сервера, и используются только программой с открытым кодом rclone и скриптами владельца. Файлы проходят через сервер транзитом между хранилищами и после передачи на нём не остаются. В журналах на сервере записываются имена, размеры, контрольные суммы и время передачи файлов.

5. Передача третьим лицам

Данные, полученные через API Google, никому не передаются, не продаются и не раскрываются.

6. Хранение и отзыв доступа

Владелец может в любой момент отозвать доступ приложения на странице myaccount.google.com/permissions; отзыв делает сохранённые токены недействительными. Все файлы в Google Диске остаются под управлением владельца через сам Google Диск.

7. Политика Google в отношении пользовательских данных

Использование информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

8. Контакт

Вопросы по этой политике можно направить на адрес поддержки, указанный на экране входа Google (экране согласия) приложения.
